## 原失败与修复

[旧 CI run 42470260500](https://github.com/wenhaogege66/studytrace/actions/runs/42470260500) 的格式、Lint、类型、单元测试与构建均成功，但浏览器测试仍等待“新建任务”“任务台还是空的”等旧入口，重复超时后取消。

本次修复：

- 创建流程改为真实引导页，统一当前学习计划、菜单、完成确认和空状态的测试定位。
- 视觉加载失败按有限重启后的实际状态断言，继续验证计时和手动复盘可用。
- 增加独立授权和准确的 `record_observation_coverage`、`heartbeat_observation_run` 测试契约；不引入 AI 报告接口或功能。

- 只有当前观察面板尝试开启过服务端摄像头区间，才发送关闭清理。已获数据库成功响应或查询确认的终态，不再重试活动会话的关闭操作；数据库终态限制未放宽。
- 全部步骤已勾选时，结束对话框提示返回后对照完成标准确认完成计划；未全部完成时保留下次新开一段的说明。不改变生命周期和布局。
